# Workflow

Jedini file koji moras zapamtiti da postoji. Citaj dok ne ude u prste.

## Pocetak storyja
1. Otvori story file u docs/stories/
2. Nova Claude Code sesija (/clear)
3. Plan mode ON ako dira vise od jednog filea
4. Procitaj plan, ispravi, tek onda pusti

## Tijekom
5. Svaki put kad nesto radi -> commit
6. Kontekst >50% ili odgovori postaju genericki -> /clear
7. Git komande radi u drugom terminalu, ne kroz Claude Code

## Kraj storyja
8. Pokreni igru, provjeri acceptance criteria
9. Commit + merge u main
10. Ako sam nesto naucio o feelu -> docs/playtest-log.md
11. Ako sam 3. put radio isti tip zadatka -> kandidat za skill

## Kraj dana
12. Update docs/open-questions.md, push

## Podjela alata
- Browser: design, GDD rasprave, "kako se u Godotu radi X", pregled dokumenata
- Claude Code: scaffolding, implementacija storyja, bugfix, refactor
- Drugi terminal: sve git komande
