# Alternativne vizije igre

Nisu u TDD-u i ne gradi za njih. Cekaju prvi playtest.
Sve tri su varijacije istog para pravila: sto melee pogodak proizvodi
(ResourceGenerationRule) i pod kojim uvjetom se karta smije igrati
(CardCastCondition). Zato oboje mora biti data, ne kod.

## A — Tower push
Soulslike combat daje samo manu. Mana ide u minione koji ne napadaju
igraca izravno nego rusе protivnicki toranj. Cilj mecа je toranj, ne HP.

## B — Cast on connect
Karta se moze odigrati samo ako je soulslike napad prosao (connect).
Melee prestaje biti izvor resursa i postaje uvjet pristupa kartama.

## C — Stun preko miniona
Jedini nacin stunanja protivnika je spawnanje miniona. Uklanja direktni
stun iz melee kompleta.
